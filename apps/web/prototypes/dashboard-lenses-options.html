Dashboard Grana: 3 opciones

Las tres mantienen la base visual actual. Cambia la prioridad de la pregunta que responde la pantalla.

A · Conservadora B · Consumo primero C · Control diario D · Caja + lectura E · Caja + compromiso F · Diferente

Opción A

Conservadora: el dashboard actual, con compromiso visible

Mantiene el orden actual casi intacto. Solo agrega una banda de compromisos entre caja y mes, y rotula "En qué se fue" como consumo devengado.
